> 2개의 벡터가 얼마나 닮았는지를 숫자로 표현하기 위해 필요한 개념

> 내적은 두 벡터의 같은 위치 성분끼리 곱한 뒤 더한 scalar 값
> 값이 클수록 두 벡터가 서로 비슷하다고 할 수 있음
> 그리고 내적은 a의 크기와 b의 크기를 곱한 값에 두 벡터 사이의 각을 곱한 값이라고 할 수 있음
> a · b = |a| x |b| x cos(θ)
> 그러므로 cos(θ) = 내적 / 두 벡터의 크기의 곱
> 코사인 유사도는 항상 1부터 -1 사이의 값을 가지며 1은 같은 방향 -1은 반대 방향 0은 직각임을 알 수 있다
> cos0 = 1, cos180 = -1, cos90 = 0 이니까

> 임베딩 공간
> 객체를(단어, 이미지, 그래프 등) 연속 공간의 벡터에 매핑한 공간을 임베딩 공간이라고 한다.
> 기계가 이해할 수 있게 숫자의 나열인 벡터로 바꿨달까...
> 고정된 크기의 연속적인 실수 벡터로 변환하는 기법
> 크게는 정적 단어 임베딩 방식과 동적 문맥 반영 임베딩 방식이 있다고 한다.
> One-Hot Encoding, TF-IDF, Word2Vec, ELMo, Transformer 기반 등..
