
> Fully connected layer
> y = XW + b
> X의 shape는 배치 크기 x 입력 차원이고 W의 shape는 입력 차원 x 출력차원


``` mermaid
flowchart LR
    X["X<br/>(2, 3)<br/>샘플 2개 x 특성 3개"] --> M["X @ W"]
    W["W<br/>(3, 2)<br/>입력 3 x 출력 2"] --> M
    M --> XW["XW<br/>(2, 2)"]
    B["b<br/>(2,)<br/>출력 차원과 동일"] --> ADD["+ b"]
    XW --> ADD
    ADD --> Y["y<br/>(2, 2)<br/>샘플 2개 x 출력 2개"]
```
