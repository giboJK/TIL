## 2. 선형 독립과 선형족속
선형독립 = 어느 벡터도 나머지로 만들어낼 수 없는 상태(?)
- 전부 새로운 정보
선형종속 = 적어도 하나가 나머지의 조합으로 만들어지는 상태

그니까 중복 정보가 있는가 없는가를 선형 종속과 독립으로 알 수 있다는 것.
우리는 데이터들을 각각 벡터화하는데 이 벡터들이 서로 어떤 관계가 있는지를 중복 정보의 차원에서 이해할 수 있다.

수학적 정의
벡터 v1, v2, ... , vn에 대해
c1v1 + c2v2 + ... + cnvn = 0 일 때
c1 = c2 = ... = cn = 0 이면 선형 독립
0이 아닌 계수 조합이 하나라도 존재하면 선형종속
